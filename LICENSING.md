# Licensing

Concordance uses two standard licences, adopted through the Licensing accord (`accords/licensing/`).

| What | Licence | SPDX identifier |
| --- | --- | --- |
| Code (`core/`, `app/`, `hearth/`, `sim/`, and any other source code) | GNU Affero General Public License, version 3 or later | `AGPL-3.0-or-later` |
| Charter, accords, RFCs, specs, stories and other documents | Creative Commons Attribution-ShareAlike 4.0 International | `CC-BY-SA-4.0` |

Full texts: [`LICENSE`](LICENSE) (AGPL) and [`LICENSE-CC-BY-SA-4.0.txt`](LICENSE-CC-BY-SA-4.0.txt).

Contributions are shared on the same terms as the project ("inbound equals outbound"). See [`CONTRIBUTING.md`](CONTRIBUTING.md).
