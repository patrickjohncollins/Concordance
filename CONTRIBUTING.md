# Contributing

Anyone may contribute: code, specs, accords, translations, stories, or comments on draft RFCs.

## Signing off

By contributing, you sign the Licensing accord: you confirm the contribution is yours to give, and you share it under the project's licences (AGPL-3.0-or-later for code, CC-BY-SA-4.0 for everything else).

Until Concordance can record this with your own key, add a sign-off line to each commit:

```
Signed-off-by: Your Name <you@example.org>
```

`git commit -s` adds it for you.

## Proposing changes

- **Charter and accords:** open a proposal describing the change and why. Changes are agreed by listening first, then agreement everyone taking part can live with.
- **RFCs:** add or edit a draft in `rfc/drafts/` (see RFC 0, `rfc/0000-process.md`). Agreed RFCs are never edited; changes come as a new RFC that updates or replaces them.
- **Decisions:** record major choices in `decisions/`, not only in issue threads, so the history moves with the repository.
