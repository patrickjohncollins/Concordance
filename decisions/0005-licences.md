# Licences

Status: Accepted (stewards' circle of one, 2026-11-22)

## Context

The first commit must carry licences, and changing licences later needs every contributor's consent.

## Decision

AGPL-3.0-or-later for code; CC-BY-SA-4.0 for the charter, accords, RFCs and documents; adopted through the Licensing accord; inbound equals outbound; contributors sign off.

## Consequences

Using "or later" versions keeps future licence versions available.
