# Concordance

*Concordance* (from the Latin for "hearts together") is a way for people to look after each other: sharing what we have, governing fairly what is scarce, and deciding together, in small circles anyone may join and anyone may leave.

It has three parts:

- **The Charter**, the root accord every circle shares: [`accords/charter/words/en.md`](accords/charter/words/en.md)
- **Accords**, agreements for particular purposes that grow from the Charter: [`accords/`](accords/)
- **The tool**, an open, peer-to-peer app and the hearths that carry it, specified in draft RFCs: [`rfc/`](rfc/)

In its own language, Selewa, Concordance is called *Selewa*. The language's seed is in [`accords/selewa/`](accords/selewa/).

## Where things are

| Path | What it holds |
| --- | --- |
| `accords/` | The Charter (root accord) and other accords, one folder each |
| `rfc/` | Requests for Comments: the process (RFC 0) and draft specifications |
| `design/` | The working plan, the current design document and working notes |
| `decisions/` | Decision records for major choices |
| `stories/` | Stories that carry the idea |
| `spec/` | Protocol specs, behavior specs and conformance vectors (to come) |
| `core/`, `app/`, `hearth/`, `sim/` | Code (to come) |

## Status

Everything here is a draft. The repository is hosted on GitHub as a temporary bootstrap; it moves to Concordance itself once native Git hosting works (see `decisions/0001-bootstrap-on-github.md`).
